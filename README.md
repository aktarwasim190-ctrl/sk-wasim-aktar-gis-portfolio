## Publish with GitHub Pages

1. Unzip this package.
2. Create a new **public** GitHub repository, for example `SK-Wasim-Aktar-Portfolio`.
3. Upload everything **inside this folder** to the repository root.
4. Confirm that `index.html` is visible at the top level of the repository.
5. Open **Settings -> Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then click **Save**.
8. Wait a few minutes for GitHub to show the public URL.

Do not upload the ZIP itself. Upload the unzipped files and folders.
